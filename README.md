# Marketplace SQL Analytics

Учебный SQL-проект на синтетических данных маркетплейса.

## Цель

Показать работу с реляционной моделью и бизнес-запросами, близкими к e-commerce / marketplace аналитике.

## Данные

- **5 000 пользователей**
- **16 000 заказов**
- **120 товаров**
- отдельные таблицы `orders`, `order_items`, `payments`

Схема: `users → orders → order_items → products`, отдельно `payments`.

## Что есть в `analysis.sql`

12 задач:

1. GMV, orders, buyers и AOV по месяцам
2. Top-5 городов по GMV
3. Top-3 товара внутри каждой категории
4. доля повторных покупателей
5. ARPU / ARPPU по каналам привлечения
6. 7-day moving average GMV
7. cancellation rate по каналам
8. доля категорий в GMV
9. cohort retention
10. RFM-like segmentation
11. вклад новых и существующих покупателей в GMV
12. метрики по способам оплаты

Используются `JOIN`, `GROUP BY`, `HAVING`, CTE, `FILTER`, `DATE_TRUNC`,
`ROW_NUMBER`, `NTILE` и оконные функции.

## Несколько наблюдений

- В синтетическом наборе GMV вырос с **2.9 млн** в январе до **212.2 млн** в декабре 2025; одновременно число покупателей выросло с **50** до **1836**.
- Доля repeat buyers выросла с **12.0%** в январе до **79.7%** в декабре.
- Cancellation rate по каналам близок: от **8.6%** (social) до **9.3%** (email), поэтому выраженного проблемного канала в данных нет.
- Среди городов максимальный GMV у **Самара** — около **106.7 млн**.

Данные синтетические, поэтому наблюдения нужны для демонстрации интерпретации результатов SQL-запросов, а не как бизнес-выводы о реальном маркетплейсе.

## Быстрые цифры

- GMV завершённых заказов: **731,724,747**
- cancellation rate: **9.0%**
